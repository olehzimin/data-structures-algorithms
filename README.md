# Data Structures and Algorithms in Swift
This repository contains my personal study and practice of Data Structures and Algorithms implemented in Swift.
It is organized for clarity, and learning.

### Purpose
- improve problem-solving skills
- understanding of time & space complexity
- practice common Algorithms
- learning about common Data Structures

### Run
1. Open `DataStructuresAlgorithms.xcodeproj` in Xcode  
2. Edit `main.swift` to test functions or structures  
3. Press **⌘R** to run
